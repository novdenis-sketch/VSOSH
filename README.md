# OBF-C-Guard

Система обфускации C-кода для защиты от статического анализа

## О проекте

OBF-C-Guard — это инструмент для многоуровневой обфускации исходного кода на языке C, разработанный для защиты программного обеспечения от обратной разработки и статического анализа. Проект реализован в рамках конкурса по информационной безопасности.

## Возможности

- Обфускация числовых констант - замена числовых литералов на сложные арифметические выражения
- Обфускация строковых констант - преобразование строк с использованием XOR-шифрования
- Добавление мусорного кода - вставка бессмысленных конструкций для усложнения анализа
- Анти-отладочные механизмы - защита от отладки с использованием ptrace и временных проверок
- Кросс-платформенность - работает на Unix-подобных системах

## Требования

- Python 3.9+
- Компилятор C (GCC/Clang)
- Unix-подобная ОС (Linux/macOS)
